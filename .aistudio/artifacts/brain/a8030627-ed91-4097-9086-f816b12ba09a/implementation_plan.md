# Implementation Plan: Frontend-Backend Integration & Real-Time Sync

## Overview
This plan establishes a bulletproof, high-performance connection between the FLOATE backend (WhatsApp AI bot, Firestore database, and API server) and the React frontend. It ensures instant synchronization of vendor product catalogues, 24-hour status stories, verified vendor contacts (`wa.me`), and AI buyer recommendations.

## Proposed Changes

### 1. Robust Data Architecture & Real-Time Firestore Sync
- Use Firestore real-time listeners (`onSnapshot`) on the frontend for products and merchant status stories to ensure instant updates without crashing.
- Fallback caching and resilient error boundaries to handle offline states gracefully and guarantee 100% uptime.

### 2. Vendor Storefront & Product Catalogue Integration
- Connect frontend components (`VendorStorefront.tsx`, `MarketplaceFeed.tsx`) to pull live products created by vendors via WhatsApp conversational uploads.
- Provide direct product links (`/product/:id` and `/catalog/:id`) generated by the WhatsApp bot.

### 3. 24-Hour Status Stories Feed
- Display daily vendor status photos and updates on their respective storefront profiles with a 24-hour TTL expiration timer.

### 4. Direct Vendor Chat Integration
- Ensure "Chat with Vendor" buttons route directly to the vendor's actual WhatsApp phone number (`https://wa.me/<cleaned_phone>?text=Hello,%20I%20found%20your%20product...`).

### 5. AI Buyer Recommendations & Catalogue Links
- When buyers query products on WhatsApp, include clickable direct catalogue links (`🌐 Product Page: https://...`) in recommendation cards.

## Verification Plan
- Compile and lint applet (`compile_applet`, `lint_applet`) to ensure zero errors.
- Verify real-time updates and API endpoints in development preview.
